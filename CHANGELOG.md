# Changelog

- Spring Boot Maven proje algılama eklendi.
- On production-readiness rule'u tamamlandı.
- Environment placeholder farkındalıklı secret kontrolü eklendi.
- Severity sıralı terminal raporu ve 0-100 skor eklendi.
- CI kullanımı için `--fail-on-findings` seçeneği eklendi.
- Windows, Linux ve macOS dağıtım paketleri eklendi.
- Temiz ve sorunlu fixture projelerle entegrasyon testleri eklendi.
- Maven Wrapper, Enforcer, Spotless ve JaCoCo kalite kapıları eklendi.
- CycloneDX SBOM, SHA-256 checksum ve build provenance attestation eklendi.
- CodeQL, Dependabot ve sabit SHA kullanan GitHub Actions akışları eklendi.
