# Güvenlik Politikası

## Desteklenen Sürümler

| Sürüm | Destek |
|---|---|
| `1.x` | Evet |
| `< 1.0` | Hayır |

## Güvenlik Açığı Bildirimi

Güvenlik açığını herkese açık issue olarak paylaşma. Bunun yerine
[GitHub Security Advisory](https://github.com/Haydarozlukk/boot-doctor/security/advisories/new)
üzerinden özel bildirim oluştur.

Bildirimde etkilenen sürümü, yeniden üretme adımlarını, olası etkiyi ve varsa
önerilen çözümü belirt. Secret, token veya gerçek kişisel veri ekleme.

Boot Doctor yardımcı bir statik kontrol aracıdır; güvenlik denetiminin veya code
review sürecinin yerine geçmez.
